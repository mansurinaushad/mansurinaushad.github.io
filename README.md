# Apex Cloud - Responsive SaaS Landing Page (Day 3 Task)

A clean, responsive SaaS landing page developed with **Bootstrap 5**, semantic **HTML5**, and custom **CSS3** for the Apex Lark Full Stack Development Internship.

---

## 🛠 Features & Bootstrap 5 Components Implemented

The project satisfies all Day 3 criteria and incorporates over 10 distinct Bootstrap 5 components:

1. **Navbar**: Sticky dark navbar with mobile hamburger toggling and responsive collapse.
2. **Alerts**: Dismissible announcement alert header.
3. **Badges**: Contextual status pills and pricing tags.
4. **Cards**: Responsive feature, metric, and tiered pricing cards.
5. **Buttons**: Custom contextual buttons with outline and solid variations.
6. **Progress Bars**: Animated and multi-colored status bars.
7. **Carousel**: Dynamic multi-item testimonial quote slider.
8. **Accordion**: Multi-panel interactive FAQ disclosure element.
9. **Forms**: Multi-column contact and authentication forms with standard client-side validation (`needs-validation`).
10. **Modals**: Demo modal dialog and dashboard sign-in prompt.
11. **Pagination**: Compact pagination component demonstrated in the footer.
12. **Grid System & Utility Classes**: Fluid mobile-first 12-column layout with responsive flex utilities (`d-flex`, `flex-column`, `flex-sm-row`), breakpoints (`col-sm`, `col-md`, `col-lg`), and spacing (`py-*`, `g-*`).
